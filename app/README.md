# コドモナ・サーガ プロトタイプ（育成・配合・バトル・スカウトの統合ループ）

設計書 [`../docs/design-decisions.md`](../docs/design-decisions.md) と
[`../docs/game-design.md`](../docs/game-design.md) の中核体験を確かめるプロトタイプ。
上部タブ **「そだてる」「バトル」「配合」** が、**ひとつの所持コレクション（localStorage 永続）を共有**してループする。

> **コアループ**：そだてる（育成＋編成）→ ぼうけん（章・ステージ→4対4ルーレット）→ スカウト（仲間化→コレクション追加）
> → 配合（親2体→新個体）→ また育てる … すべて同じコレクションを介してつながる。

Vite + React + TypeScript（PWA）。戦闘・配合・成長の決定ロジックは UI から完全分離した純TSで、
シード乱数により再現可能・ユニットテスト済み（**57件合格**）。

## 何が触れるか

### そだてるタブ（育成＋編成）
- **コレクション**から所持個体を選び、育成・編成できる（すべて永続）。
- **縦式リール**：円形回転ではなく、縦一列のパネルが上下スクロールし中央の停止ラインで止まる。`スピン`で手触り確認。
- **★ランク / ミス枠**：パネルごとの強さ表示と、止まると失敗する「ミス」枠。
- **オレカ式ランダム成長**：`レベルアップ`で1枠がランダムに別の技／上位技へ変化（まれに飛び級・必殺出現）。
- **ロック**：パネルをロックして変化対象から除外。
- **編成**：`編成に入れる/外す`で出撃メンバー（最大4）を決める。バトルに直結。

### 4対4バトルタブ
- **最大4対4のルーレット式バトル**：味方の手番でリールを回し、停止した行動を実行。
- **ターゲット指定**：敵カードをタップしてロック（未指定はAIが弱点/低HPを自動選択）。
- **属性相性**（火水風地光闇無）・**会心/ミス/暴走**・**状態異常**（毒/麻痺/眠り/バフ/デバフ等）。
- **単体/全体/ランダム/回復/バフ/吸収**の各行動、**敵AI**、勝敗判定。
- **スカウト（DD・設計書6章）**：戦闘でたまる共通ゲージが満タンになると、敵を狙って仲間化を試行。
  - 成功率＝難度★ × 残HP × 状態異常 × ランク × なつきやすさ ＋ **絆ボーナス**（5〜95%）。
  - 失敗しても**絆ポイント+1で次回成功率UP**（低確率を粘らせない設計）＋対象が一時的に怒る軽リスク。
  - 成功率は **%＋☆** で表示。ボス/配合専用はスカウト不可。仲間にすると敵が1体減る。
  - **スカウト成功＝コレクションに新個体として永続追加**（そだてる/配合で使える）。
- **オート**で全自動進行も可能。

### ぼうけんタブ（章・ステージ）
- `chapters.json` から **全10章 × 各4ステージ（通常3＋ボス）** を生成（敵編成はステージIDをシードに決定論生成）。
- **章チップ＋ステージ一覧**：推奨Lv・敵数・主要系統アイコン・クリア★・ボス表示。
- **解放制**：直前ステージのクリアで次が、章ボスのクリアで次章が解放。
- ステージを選ぶと、**編成（party）で 4対4 バトル**が始まる。
- **初回クリア報酬**：編成メンバーが1レベルずつ成長（バトル→育成の還元）。クリア状況は永続。

### 配合タブ
- コレクションから**親2体を選択**→**プレビュー**（子系統・ランク帯・候補・属性・特殊配合バッジ）→
  **継承スキル選択（最大2）**→確認→**実行**。
- 結果は**子個体＋リール＋系譜（世代）**を表示。親は消費され、子がコレクションに加わる。

データは単一ソース [`../data/monsters.json`](../data/monsters.json) / [`../data/fusion_rules.json`](../data/fusion_rules.json) を直接読み込む。
所持個体・編成・図鑑は **localStorage**（`kodomona-store-v1`）に保存される。

## 開発

```bash
cd app
npm install
npm run dev        # 開発サーバ（スマホ実機は表示される Network URL を開く）
npm test           # ユニットテスト（vitest）
npm run build      # 本番ビルド（tsc + vite）→ dist/
npm run preview    # ビルド結果をローカル確認
```

## ロジックとUIの分離（設計書 12-8 準拠）

- 戦闘の行動決定（停止位置・成長変化・ダメージ計算・状態異常・AI）は `reel/` と `battle/` の純TS。
  乱数はシード注入で**再現可能・テスト可能**。`Battle` クラスは `takeAllyTurn`/`takeEnemyTurn` が
  1手番ぶんを解決し `BattleEvent[]` を返す（演出はUI側が再生）。
- アニメーションは `VerticalReel.tsx` / `BattleScreen.tsx`。停止パネルは事前に確定し、表示は後追い
  （チート/同期ズレ防止）。
- この分離により、将来のオートバトル・リプレイ・サーバ同期へ拡張しやすい。

## このプロトタイプに含まないもの（次フェーズ）

覚醒（見た目変化）・ストーリー演出・図鑑画面・クラウドセーブ・サウンド・
配合の逆引き/おすすめ・ボス専用ギミック（属性シフト等は未実装）。
本プロトタイプは育成・配合・バトル・スカウト・章進行が**ひとつのコレクションを介してループする**ことの検証に絞っている。
