# 縦式リール プロトタイプ（コドモナ・サーガ）

設計書 [`../docs/design-decisions.md`](../docs/design-decisions.md) **DD-001** で確定した
「縦式パネル・リール＋オレカ式ランダム成長」の体験を確かめる、単一コンポーネント・プロトタイプ。

Vite + React + TypeScript（PWA）。バトルの行動決定ロジックは UI から分離した純TSで、ユニットテスト済み。

## 何が触れるか

- **縦式リール**：円形回転ではなく、縦一列のパネルが上下スクロールし中央の停止ラインで止まる。
- **おまかせ / ストップ（手動）**：自動停止と、タップで狙い止めする手動モード。
- **★ランク / ミス枠**：パネルごとの強さ表示と、止まると失敗する「ミス」枠。
- **オレカ式ランダム成長**：`レベルアップ`で1枠がランダムに別の技／上位技へ変化（まれに飛び級・必殺出現）。
- **ロック / 振り直し**：パネルをロックして変化対象から除外、直近の変化をリロール（事故救済）。
- **シード**：同じシードなら同じ結果（再現可能）。

データは単一ソース [`../data/monsters.json`](../data/monsters.json)（schema v2）を直接読み込む。

## 開発

```bash
cd app
npm install
npm run dev        # 開発サーバ（スマホ実機は表示される Network URL を開く）
npm test           # ユニットテスト（vitest）
npm run build      # 本番ビルド（tsc + vite）→ dist/
npm run preview    # ビルド結果をローカル確認
```

├── index.html

## ロジックとUIの分離（設計書 12-8 準拠）

- 行動決定（停止位置・成長変化）は `reel/` の純関数。乱数はシード注入でテスト可能・再現可能。
- アニメーションは `VerticalReel.tsx`。停止パネルは事前に確定し、表示は後追い（チート/同期ズレ防止）。
- この分離により、将来のオートバトル・リプレイ・サーバ同期へ拡張しやすい。

## このプロトタイプに含まないもの（次フェーズ）

敵ユニット・ダメージ計算・4対4の戦闘進行・スカウト・配合・覚醒・章進行。
本プロトタイプは「リールの手触り」と「育成の引き」の検証に絞っている。
