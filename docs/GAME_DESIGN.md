# GAME_DESIGN — ゲームシステム仕様

## ステータス
- 一次: STR / VIT / INT / DEX / LUK。
- 派生は `src/stats/stats.ts` の `computeDerived` **一箇所のみ**で算出:
  maxHp / maxMp / physAtk / magAtk / def / magDef / accuracy / evasion / critRate /
  atkSpeed / moveSpeed。
- 合成順: 職業補正(base) ＋ レベル成長 ＋ 装備 statMods ＋ パッシブ → computeDerived
  → 装備 derivedMods を上乗せ。

## 職業
- 1次職5系統（戦士/魔法/僧侶/盗賊/テイマー）→ 4次職までのツリー（計21職目安、Phase 2以降）。
- マルチジョブ育成・転職。武器タグ制限（12種）と防具系統制限、レア度→職業tierゲート。
- 見た目は職業固定（`appearance` テクスチャキー）。

## スキル（データ駆動の効果型・初日から設計）
- 系統別ツリー（前提技・必要Lv・系統ロック・職位 minTier ロック）。
- 効果型 `effect`: `damage` / `heal` / `buff(持続)` / `projectile` / `summon`。
  実装は段階的でよいが、データの形は先に固定。

## 属性・状態異常（Phase 1 から実運用）
- 火/氷/雷/毒/聖/闇＋無。敵に弱点(×1.5)/耐性(×0.5)。
- 属性ヒットで状態異常（火傷/毒=DoT 500ms刻み、凍結/麻痺=行動停止）。発生率28%、弱点時1.5倍。
- 武器に element、スキルは `skill.element` 優先 → 無ければ武器属性。ダメージ数字を属性色に。
- ロジックは `src/combat/elements.ts`（純TS）。

## クエスト
- 「通常」と「大型狩猟」の2枠＋★ランク1〜7（ランクごとに星の色を変える）。
- 大型狩猟 = 受注 → 専用アリーナへ出発 → ボス討伐 → 反復可（素材周回）。ボスごとに専用アリーナ。

## ボス（行動パターンをデータ駆動に・Phase 1）
- 看板ボス12体、Lv6〜80 に分散。各ボスに固有素材 → 専用装備レシピ。
- 予告円→範囲攻撃、突進、弾幕、取り巻き召喚、HP50%で怒りモード。
- 体当たりだけのボスにしない（前作最大の反省点）。図形描画で作れるので絵は不要。

## 装備 / クラフト / ドロップ
- 9スロット（頭/胴/手/腰/足/背/武器/装飾1/装飾2）。装飾は指輪(攻撃系)と護符(防御系)。
- レア度 R1〜R10（色帯導出）。
- クラフト = 直接生産＋強化（下位装備消費）。全レシピ素材の入手可能性をテストで常時検証。
- ドロップ = データ駆動テーブル＋seedable RNG＋ボス初回確定＋レア演出。

## 進行 / エンドゲーム
- 1職を4次職まで約20時間を目安（テストで総EXP÷想定時給を検証）。
- エンドゲーム: `ItemInstance`（ランダム性能の装備個体）をセーブスキーマに初日から確保
  （後付けが最大の改修になるため）。
