# モンスター30体 詳細設計

初期実装用の30体（コドモナ）。系統10種をカバーし、各系統で低ランク入門個体〜高ランク個体が揃うよう設計。
機械可読版は [`../data/monsters.json`](../data/monsters.json)。

> 命名・デザインはすべてオリジナル。「可愛い要素」と「かっこいい要素」を各体に明記し、
> 育成・覚醒・配合で前者から後者へ変化していく設計を前提にしている。

凡例：ランク `G<F<E<D<C<B<A<S<SS` / 属性 `火・水・風・地・光・闇・無` / スカウト難度 ★1(易)〜★5(難)

## 獣系（ケモノ／キーカラー: オレンジ）

### 01. モコル
- **系統 / ランク / 属性**：獣 / F / 地
- **見た目**：毛玉のような丸い四足獣。短い手足、ふさふさの尻尾。
- **可愛い要素**：転がるように歩く、大きな丸い目、鳴くと尻尾が膨らむ。
- **かっこいい要素**：覚醒で前傾の俊敏な獣へ。牙とたてがみが伸びる。
- **得意な役割**：物理アタッカー（序盤の主力）。
- **初期技**：ひっかき / からだ当たり / うなり。
- **成長後の方向性**：攻撃と素早さ型。中盤まで前線を張れる。
- **配合での使い道**：獣系の基礎素材。獣×竜で竜獣系の足がかり。
- **スカウトしやすさ**：★1（最初の仲間に最適）。

### 02. トゲリス
- **系統 / ランク / 属性**：獣 / E / 地
- **見た目**：背に小さなトゲを持つリス型。頬袋がぷっくり。
- **可愛い要素**：頬に木の実を溜める、丸まって眠る。
- **かっこいい要素**：トゲを逆立てる威嚇モーション。
- **得意な役割**：物理＋搦め手（トゲで反撃・ひるみ）。
- **初期技**：トゲづき / ためこむ（防御UP） / すばやけり。
- **成長後の方向性**：防御寄りアタッカー。カウンター型。
- **配合での使い道**：獣系に「反撃」スキルを運ぶ素材。
- **スカウトしやすさ**：★2。

### 03. ニャグモ
- **系統 / ランク / 属性**：獣 / D / 風
- **見た目**：雲のたてがみを持つ猫型獣。足元がもやもや。
- **可愛い要素**：ふわふわ浮く、ごろごろ喉を鳴らす。
- **かっこいい要素**：高速で残像を残す疾走。
- **得意な役割**：速攻アタッカー（先手で撹乱）。
- **初期技**：かぜのつめ / はやがけ（素早さUP） / みだれ爪。
- **成長後の方向性**：素早さ特化、先制デバフ。
- **配合での使い道**：風属性＋速攻を他系統へ継承。
- **スカウトしやすさ**：★3。

## 設計上のバランスメモ

- 各系統に「F〜E入門」「C〜D中堅」「A〜B高ランク」を配置し、配合で系統内の階段を上がれる。
- スカウト難度は概ね **低ランク＝易 / 高ランク＝難** に対応。図鑑序盤が気持ちよく埋まる。
- 役割（アタッカー/タンク/ヒーラー/サポート/搦め手）が全系統に散らばり、編成の幅を確保。
- オメガル(#30)のみ配合専用にし、「目指す頂点」を1体提示（MVPでは特殊配合レシピを1つ実装）。
