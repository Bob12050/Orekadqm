## 開発規律
- 変更のたび: `npm run typecheck` / `npm run validate-data` / `npm run test` / `npm run build`
- データはハードコードせず defs に置く。派生ステは `computeDerived` 一箇所。
- 疎結合連携は型付き EventBus のみ。巨大クラス禁止。
