# 全10章 ストーリー・進行設計

難易度・戦略性・育成度・配合の重要度が1章→10章へ段階的に上がる。
理不尽な跳ね上がりを避け、各章で「新システムを学びながら強くなる」構成。
機械可読版は [`../data/chapters.json`](../data/chapters.json)。

難易度曲線の方針：
- **1〜3章「学ぶ」**：基本操作・スカウト・属性・状態異常・簡易配合を順に習得。
- **4〜6章「組み立てる」**：特殊配合・盤面拡張・覚醒で、編成と育成を能動的に設計。
- **7〜9章「極める」**：高度な継承・個性固定・多段配合。戦略の最適化が問われる。
- **10章「総決算」**：全システム総合の多段階ボス戦。

推奨パーティ強さは「平均Lv ＋ 最低ランク帯」で表記（目安）。

## 第1章 めざめの草原
- **舞台**：星のかけらが降り注ぐ、みどりの草原「ソルプレイン」。
- **主要テーマ**：はじまりの出会い。コドモナと心を通わせる「共鳴」を学ぶ。
- **主な系統**：獣・植物。
- **解放システム**：バトル基礎、ターゲット指定、ルーレット（おまかせ）、スカウト基礎、図鑑、編成。
- **推奨強さ**：平均Lv 5〜10 / ランクF〜E。
- **難易度の特徴**：敵は1〜2体中心。チュートリアル兼。失敗してもやり直しやすい。
- **ボスモンスター**：**ヌシモコル**（巨大化したモコルの主／獣・地）。
- **ボスギミック**：HP50%で「ふんばり」（防御UP）。倒すより、まず削って隙を作る基礎を教える。スカウト不可。
- **クリア報酬**：簡易配合の解放予告、獣系・植物系の素材、コドモナ枠拡張。
- **次章への引き**：草原の水辺で「にごり」が広がる。源流の水郷へ。

## 第2章 せせらぎの水郷
- **舞台**：川と湖が広がる水郷「ミナモ」。
- **主要テーマ**：仲間を増やし、初めての配合で新しい命を生む。
- **主な系統**：水棲・鳥。
- **解放システム**：**簡易配合（汎用配合）**、配合プレビュー、おすすめ配合。
- **推奨強さ**：平均Lv 10〜15 / ランクF〜D。
- **難易度の特徴**：敵が3体編成に。属性（水・風）の有利不利を意識させる。
- **ボスモンスター**：**ウズマキガニ**（渦を操る大蟹／水棲・水）。
- **ボスギミック**：「うずまき」で全体素早さダウン → 先制を崩す。風属性や素早さ補正で対抗を学ぶ。
- **クリア報酬**：水棲・鳥系素材、配合用コイン、図鑑報酬。
- **次章への引き**：森の奥から精霊のささやき。にごりの根が森へ伸びる。

## 第3章 ささやきの森
- **舞台**：光が差し込む深い森「ウィスパーウッド」。
- **主要テーマ**：属性相性と状態異常を駆使した戦い。
- **主な系統**：植物・精霊。
- **解放システム**：**属性相性の本格運用**、状態異常（毒・眠り・麻痺）、弱点解析表示。
- **推奨強さ**：平均Lv 15〜20 / ランクE〜D。
- **難易度の特徴**：敵が状態異常を使い始める。回復役・浄化役の重要性が出る。
- **ボスモンスター**：**モリオウ**（森の王たる古樹／植物・地）。
- **ボスギミック**：「やどりぎ」で継続回復＋とりまき召喚。デバフ・全体技・状態異常解除の使い分けを要求。
- **クリア報酬**：精霊系素材（ヒーラー入手機会）、状態異常スキル素材。
- **次章への引き**：森を抜けた先に、乾いた砂漠と古代遺跡。特別な配合の噂。

## 第4章 かわいた砂漠
- **舞台**：灼熱の砂漠と眠る遺跡「ドライランド」。
- **主要テーマ**：特殊配合の発見と、編成の組み立て。
- **主な系統**：物質・獣。
- **解放システム**：**特殊配合の解放**、配合逆引き（基礎）。
- **推奨強さ**：平均Lv 20〜28 / ランクD〜C。
- **難易度の特徴**：高防御の物質系が増え、火力不足だと長期戦に。属性貫通・デバフが有効に。
- **ボスモンスター**：**サンドヴォルム**（砂を泳ぐ大蟲／物質・地）。
- **ボスギミック**：地中に潜って攻撃を回避（潜行中はダメージ減）→ 浮上時に集中攻撃する「タイミング戦」。
- **クリア報酬**：物質系高ランク素材、特殊配合レシピのヒント、メタル系の足がかり。
- **次章への引き**：遺跡の壁画に「空を翔ける竜」。竜の谷への道が開く。

## 第5章 はぐれ竜の谷
- **舞台**：切り立った渓谷「ドラグキャニオン」。
- **主要テーマ**：強敵・竜との対峙。ルーレット盤の最適化。
- **主な系統**：竜・鳥。
- **解放システム**：**ルーレット枠拡張（最大6→）**、技強化の本格運用。
- **推奨強さ**：平均Lv 28〜36 / ランクC〜B。
- **難易度の特徴**：単体高火力の竜が出現。盤面を「安定型/博打型」に調整する意義が出る。
- **ボスモンスター**：**嵐竜ライゼル（野生の王個体）**（竜・風／#06の特別個体）。
- **ボスギミック**：HP段階ごとに「らいげき連発モード」へ。耐久と火力のバランス、麻痺対策を要求。撃破後、共鳴クエストで限定スカウトのチャンス。
- **クリア報酬**：竜系高ランク素材、ルーレット枠拡張アイテム。
- **次章への引き**：谷の奥から機械音。人ならぬ手で作られた都市の存在。

## 第6章 からくり工房街
- **舞台**：歯車と蒸気の機械都市「ギアトピア」。
- **主要テーマ**：覚醒（進化）による一段上の強化。
- **主な系統**：機械・物質。
- **解放システム**：**覚醒（進化）の解放**、装甲・自己強化の理解。
- **推奨強さ**：平均Lv 36〜45 / ランクC〜B。
- **難易度の特徴**：硬く・自己強化する機械系。長期化を避ける火力設計と封印（強化阻止）が鍵。
- **ボスモンスター**：**暴走機巧（オメガル原型機）**（機械・無）。
- **ボスギミック**：「アダプトシフト」で弱点属性を変化させる → 複属性パーティor属性切替で対応。怒りモードで行動回数増。
- **クリア報酬**：覚醒素材、機械系高ランク素材、オメガル特殊配合の手がかり（断片）。
- **次章への引き**：都市の地下市場で囁かれる「影の商人」。よいやみの市場へ。

## 第7章 よいやみの市場
- **舞台**：怪しい灯がともる夜市「ノクトバザール」。
- **主要テーマ**：状態異常・搦め手の応酬、スカウトの極意。
- **主な系統**：悪魔・魔法。
- **解放システム**：**スカウト特化編成**、配合逆引き強化、状態異常コンボの本格化。
- **推奨強さ**：平均Lv 45〜54 / ランクB〜A。
- **難易度の特徴**：敵が呪い・封印・暗闇を多用。状態異常耐性・浄化・封印返しの編成知が問われる。
- **ボスモンスター**：**影商人ヴェルゼ**（悪魔・闇／#24個体）。
- **ボスギミック**：全体に「のろい（持続デバフ）」を撒き、封印で必殺を止める。浄化役と封印耐性、短期決戦を要求。撃破後、共鳴クエストで限定スカウト。
- **クリア報酬**：悪魔系高ランク素材、スカウト特化スキル、逆引き機能の拡張。
- **次章への引き**：市場の地図が示す、北の凍てつく霊峰。星のかけらの濃い気配。

---

## 第8章 こおりの霊峰
- **舞台**：吹雪く高峰「フロストピーク」。
- **主要テーマ**：高度な継承・個性固定。育成の最適化。
- **主な系統**：精霊・竜。
- **解放システム**：**高度なスキル継承／個性固定（同個性親の重ね）**。
- **推奨強さ**：平均Lv 54〜63 / ランクA〜S手前。
- **難易度の特徴**：氷の全体攻撃と凍結（行動阻害）。継承で耐性・特性を整えた個体が要る。"厳選"の入口。
- **ボスモンスター**：**氷霊王**（精霊・水／光と氷の王）。
- **ボスギミック**：「絶対零度」（全体大ダメージ＋鈍足）を詠唱 → 詠唱中に火力集中or防御で凌ぐ「読み合い」。属性シフトあり。
- **クリア報酬**：精霊系最高ランク素材、個性固定素材、覚醒上位素材。
- **次章への引き**：霊峰の頂から見える、空に浮かぶ「星のかけら回廊」。

## 第9章 ほしのかけら回廊
- **舞台**：天空に浮かぶ光の回廊「ステラコリドー」。
- **主要テーマ**：全系統混成の総合力。多段配合の真価。
- **主な系統**：全系統混成（敵が多彩な属性・役割で構成）。
- **解放システム**：**多段配合の本格運用**（高世代SS素材づくり）、最強編成研究。
- **推奨強さ**：平均Lv 63〜72 / ランクS。
- **難易度の特徴**：敵編成が4体フルで役割分担（壁＋火力＋回復＋妨害）。こちらも穴のない編成が必須。
- **ボスモンスター**：**堕ちた星霊**（精霊／闇に染まった元・守護精霊）。
- **ボスギミック**：3フェーズ。光→闇→混沌で行動様式が一変。回復封じ・全体即死級技・とりまき。総合的な対応力を要求。
- **クリア報酬**：SS素材、多段配合レシピ、最終章への鍵。
- **次章への引き**：回廊の果て、すべてのにごりの源「星の中心」が脈打つ。

## 第10章 せかいのまんなか
- **舞台**：世界の核「アルカ・コア」。
- **主要テーマ**：総決算。学んできたすべてを使う最終決戦。
- **主な系統**：全系統＋SS級。
- **解放システム**：全システム総合（特別な制限・条件なしで全要素フル活用）。
- **推奨強さ**：平均Lv 72〜85 / ランクS〜SS。
- **難易度の特徴**：最高難度。編成・育成・盤面・配合・ターゲット判断・スカウト準備のすべてが問われる。
- **ボスモンスター**：**星喰みアビス**（混沌の化身／多段階）。
- **ボスギミック**：
  1. 第1段階：全属性ローテーション＋とりまき召喚。
  2. 第2段階：回復・蘇生封印、全体高火力。耐久と火力の両立。
  3. 最終段階：「世界喰らい」カウントダウン（一定ターンで全体大ダメージ）→ 速攻と凌ぎの最終択。
- **クリア報酬**：エンディング、最高ランク報酬、クリア後コンテンツ（共鳴クエスト全開放、最強配合への道、図鑑コンプ要素）。
- **次章への引き（クリア後）**：鎮めたはずの星のかけらが、新たな可能性として各地に。やり込み（高難度再戦・特殊配合コンプ・全スカウト）へ誘導。

## 章設計のバランスメモ

- **新システムは1章につき1〜2個**だけ解放し、消化不良を防ぐ。
- ボスは毎章「これまで学んだ要素＋新要素1つ」を試す設計（例：3章＝状態異常解除、6章＝属性シフト対応）。
- 推奨強さは前章クリア時の戦力で**少し背伸びすれば届く**水準（育成・配合の動機付け）。
- 5章・7章・9章のボスは**撃破後に限定スカウト**の共鳴クエストを用意し、長期目標を点在させる。
- MVPでは**第1章のみ**を完全実装（チュートリアル＋数ステージ＋ヌシモコル戦）。
